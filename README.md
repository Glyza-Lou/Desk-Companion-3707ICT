# Desk-Companion-3707ICT
Contains the complete project source code. The Wokwi project was ran locally but a link to the web project is provided. The link to the public ThingSpeak dashboard is also provided. Within the DESK COMPANION folder you will see the diagram.json file containing the Wokwi diagram sketch. The src folder will contain the sketch.cpp code that will have all the source code for the Desk Companion system including the sensor logic, state machine, adaptive AI baseline, actuator control, and ThingSpeak HTTP integration.

## Hardware components include:
- ESP32 DevKit V1
- DHT22 (temperature & humidity)
- Photoresistor / LDR
- PIR motion sensor
- RGB LED
- Servo motor (simulated fan)
- Buzzer

## Libraries include:
- DHT sensor library
- Adafruit Unified Sensor
- ESP32Servo
