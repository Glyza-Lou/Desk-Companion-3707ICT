# Desk-Companion-3707ICT
Contains the complete project source code. The Wokwi project was ran locally but a link to the web project is provided.

## Hardware components include:
- ESP32 DevKit V1
- DHT22 (temperature & humidity)
- Photoresistor / LDR
- PIR motion sensor
- RGB LED
- Servo motor (simulated fan)
- Buzzer

## Libraries include:
- DHT sensor library
- Adafruit Unified Sensor
- ESP32Servo
